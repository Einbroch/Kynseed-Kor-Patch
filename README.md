# Kynseed 한국어 패치 (Nintendo Switch)

[![최신 릴리스](https://img.shields.io/github/v/release/Einbroch/Kynseed-Kor-Patch)](https://github.com/Einbroch/Kynseed-Kor-Patch/releases/latest)

Kynseed(PixelCount Studios) Switch판의 **한국어 슬롯을 고품질 번역으로 교체**하는
LayeredFS 패치입니다.

Kynseed Switch판은 이미 공식 한국어를 탑재하고 있습니다. 다만 그 번역은 기계번역
품질이라 고유명사가 그대로 남고, 주민 말투가 한 줄마다 뒤바뀝니다. 이 패치는 없는
한국어를 새로 만드는 게 아니라 **기존 한국어 슬롯을 교체**합니다.

| 항목 | 값 |
|---|---|
| 대상 | `0100783020A1A000` + **업데이트 1.0.0.54 (v262144)** |
| 방식 | LayeredFS (`romfs/` overlay) — 원본 파일을 고치지 않음 |
| 범위 | 텍스트 21,000행 / 63파일 · 폰트 한글 110자 추가 · 이미지 6건 |
| 최신 | **v1.1.0** — 주민 대사 어조 교정 |

## 내려받기

[**Releases**](https://github.com/Einbroch/Kynseed-Kor-Patch/releases/latest) 에서
`0100783020A1A000.zip` 을 받으세요. `SHA256SUMS.txt` 로 무결성을 확인할 수 있습니다.

ZIP 안에는 `romfs/` 폴더 하나만 들어 있고 그 아래 패치 파일 69개만 있습니다.

```
romfs/
├─ Data/Text/KO/              (63개 — 한국어 텍스트)
└─ Graphics/
   ├─ Splash/load_chicken.png (로딩 애니메이션)
   └─ SpriteSheets/HandMade/  (폰트 아틀라스 2개 + 이미지 3개)
```

## 설치

자세한 절차는 [`INSTALL.md`](INSTALL.md) 를 보세요. 요약하면,

- **실기 (Atmosphère)**: `/atmosphere/contents/0100783020A1A000/romfs/` 에 넣습니다
- **PC 에뮬레이터**: 모드 폴더의 `load/0100783020A1A000/<이름>/romfs/` 에 넣습니다
- **Android Eden**: 게임 길게 누르기 → 애드온 → `Mods and Cheats` 로 폴더를 가져옵니다

**한국어 슬롯을 선택해야 패치가 보입니다.** Kynseed는 시스템 언어와 별개로 세이브의
`ConfigSetup.ini` 에 언어를 저장하고, 게임 안 설정에는 언어 항목이 없습니다.
한글 `로딩` 이 나오는데 메뉴만 영어라면 패치는 정상 로드된 상태이니
[`INSTALL.md`](INSTALL.md) 의 `Language=KO` 절차를 따르세요.

## v1.1.0에서 바뀐 것 — 주민 말투

게임은 주민 대사를 `성격(5) × 활동(10) × 관계(5)` 로 조합합니다
(`Chat_Greeting_<활동>[<성격>][<관계>]`). 기존 번역은 이 축을 무시하고 있었습니다.

| 결함 | 이전 실측 | v1.1.0 |
|---|---|---|
| 한 주민이 줄마다 말투를 바꿈 | 성격 5종이 **전부** 해요체·반말·합쇼체를 섞어 씀 | 성격 × 관계 칸마다 하나로 통일 |
| 관계가 깊어져도 말투가 안 바뀜 | 존댓 비율 Dislike 53% / Neutral 85% / Friendly 43% / Like 30% / Love 70% — 단계와 무관 | Dislike·Neutral·Friendly=존댓, Like·Love=반말 |
| 인사말이 명사구로 번역됨 | `많은 인사`, `축복받은 인사` 가 262행 앞에 그대로 붙음 | 인사 표현으로 교체 |

| 성격 | 1인칭 | 말버릇 |
|---|---|---|
| 허풍 (Boastful) | 나/내 | 단정·과장 — `~죠`, `~거든요`, `~걸요` |
| 불평 (Complainer) | 나/내 | 투덜 — `~네요`, `~라니까요` |
| 쾌활 (Jovial) | 나/내 | 감탄·권유 — `~요!`, `~할래요?` |
| 독실 (Pious) | **저/제** | 기원문 — `~하기를 바라요` |
| 괴짜 (Quirky) | 나/내 | 엉뚱 — `~거든요`, `~더라고요` |

발화 4,799행을 검사해 1,835행을 고쳤고, 어조 게이트 6종 위반이 **2,132 → 0** 이
됐습니다. 새로 쓴 문장이 쓰는 한글 27자를 폰트 아틀라스에 추가했습니다(83 → 110자).

전체 내역은 [`RELEASE_NOTES.md`](RELEASE_NOTES.md) 에 있습니다.

한글 글리프 27자이고, 파일 구조·개수·주입 방식은 v1.0.1 과 같습니다.

아직 못 본 것: 상점·게시판·판매대 이미지 4건, 타이틀 배너, `↩` 기호, 긴 대사 줄바꿈
66행, 실기 동작.

## 제거

넣었던 `romfs` 폴더(또는 모드 폴더)를 지우면 됩니다. 원본 파일을 고치지 않는
overlay 라서 지우면 원래 상태로 완전히 돌아가고, 세이브 데이터에도 영향이 없습니다.

있지 않고 앞으로도 포함하지 않습니다. 패치를 쓰려면 Kynseed 정품과 업데이트
1.0.0.54 가 있어야 합니다.
