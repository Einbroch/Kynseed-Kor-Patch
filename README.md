# Kynseed 한국어 패치 (Nintendo Switch)

[![최신 릴리스](https://img.shields.io/github/v/release/Einbroch/Kynseed-Kor-Patch)](https://github.com/Einbroch/Kynseed-Kor-Patch/releases/latest)

Kynseed(PixelCount Studios) Switch판의 **한국어 슬롯을 고품질 번역으로 교체**하는
LayeredFS 패치입니다.

Kynseed Switch판은 이미 공식 한국어를 탑재하고 있습니다. 다만 그 번역은 기계번역
품질이라 고유명사가 그대로 남고, 주민 말투가 한 줄마다 뒤바뀝니다. 이 패치는 없는
한국어를 새로 만드는 게 아니라 **기존 한국어 슬롯을 교체**합니다.

| 항목 | 값 |
|---|---|
| 대상 | `0100783020A1A000` + **업데이트 1.0.0.54 (v262144)** |
| 방식 | LayeredFS (`romfs/` overlay) — 원본 파일을 고치지 않음 |
| 범위 | 텍스트 21,000행 / 63파일 · 폰트 한글 110자 추가 · 이미지 6건 |
| 최신 | **v1.1.2** — 실기 동작 정정 |

> ## 실기에서는 세이브 수정이 필요합니다
>
> 게임은 언어를 세이브의 `ConfigSetup.ini` 에 저장하고, 그 기본값은 게임 코드가
> 정합니다. **본체 언어를 한국어로 맞추고 세이브 없이 새로 시작해도 게임은 `EN` 으로
> 시작합니다**(2026-09-15 실기 확인). RomFS 에는 언어 기본값을 담은 설정이 없어
> LayeredFS 패치로는 이 자리를 건드릴 수 없습니다.
>
> 패치를 넣은 뒤 `ConfigSetup.ini` 의 `Language=EN` 을 `Language=KO` 로 바꾸세요.
> 절차는 [`INSTALL.md`](INSTALL.md) 에 있습니다.

## 내려받기

[**Releases**](https://github.com/Einbroch/Kynseed-Kor-Patch/releases/latest) 에서
받으세요. `SHA256SUMS.txt` 로 무결성을 확인할 수 있습니다.

| 방법 | 받을 것 | 상태 |
|---|---|---|
| 세이브의 언어값을 `KO` 로 고쳐서 쓴다 | `0100783020A1A000.zip` | **확인됨** |
| 세이브를 안 고치고 쓰고 싶다 | `0100783020A1A000-ENslot.zip` | **미검증** |

EN 슬롯 포함판은 게임이 실제로 읽는 영어 슬롯에도 같은 한국어를 넣어 두는 판입니다.
구조는 검증했지만(EN 슬롯 63파일이 KO 슬롯과 바이트 동일) 아직 화면으로 확인하지
못했습니다. 되는지 알려 주시면 문서를 갱신하겠습니다. 넣어 둔 동안에는 영어로
되돌릴 수 없습니다.

두 패키지 모두 ZIP 최상위에 안내문 [`Readme.txt`](Readme.txt) 가 들어 있습니다.
설치·문제 해결·바뀐 내용이 한 파일에 정리돼 있으니 압축을 푼 뒤 먼저 읽어 보세요.
설치할 때 복사하는 것은 `romfs` 폴더뿐이고 `Readme.txt` 는 복사하지 않아도 됩니다.

기본 패키지의 `romfs/` 아래에는 패치 파일 69개만 있습니다.

```
romfs/
├─ Data/Text/KO/              (63개 — 한국어 텍스트)
└─ Graphics/
   ├─ Splash/load_chicken.png (로딩 애니메이션)
   └─ SpriteSheets/HandMade/  (폰트 아틀라스 2개 + 이미지 3개)
```

## 설치

자세한 절차는 [`INSTALL.md`](INSTALL.md) 를 보세요. 요약하면,

- **실기 (Atmosphère)**: `/atmosphere/contents/0100783020A1A000/romfs/` 에 넣습니다
- **PC 에뮬레이터**: 모드 폴더의 `load/0100783020A1A000/<이름>/romfs/` 에 넣습니다
- **Android Eden**: 게임 길게 누르기 → 애드온 → `Mods and Cheats` 로 폴더를 가져옵니다

**한국어 슬롯을 선택해야 패치가 보입니다.** Kynseed는 시스템 언어와 별개로 세이브의
`ConfigSetup.ini` 에 언어를 저장하고, 게임 안 설정에는 언어 항목이 없습니다.
한글 `로딩` 이 나오는데 메뉴만 영어라면 패치는 정상 로드된 상태이니, EN 슬롯
포함판으로 바꾸거나 [`INSTALL.md`](INSTALL.md) 의 `Language=KO` 절차를 따르세요.

구버전 CFW 는 폴더 이름이 다릅니다 — Atmosphère 0.10 미만은
`/atmosphere/titles/...`, SX OS 는 `/sxos/titles/...` 입니다.

## v1.1.1에서 고친 것 — 언어 슬롯 메타데이터

게임은 `Data/Text/<슬롯>/Data.xml` 의 `<Code>` 로 언어를 고릅니다. 패치의 빌드 기준이
`EN` 폴더라서, 번역 대상이 아닌 필드가 EN 값 그대로 복사됐습니다.

| 필드 | 원본 KO | v1.1.0 패치 | v1.1.1 |
|---|---|---|---|
| `Code` | `KO` | **`EN`** | `KO` |
| `Name` | `Korean` | **`English Master`** | `Korean` |
| `BigGlyphs` | `1` | **`0`** | `1` |

패치를 넣으면 KO 슬롯이 자기를 `EN` 이라고 말하게 됩니다. 한국어로 설정된 본체가
코드 `KO` 인 언어를 찾으면 없으니 영어로 떨어집니다. 에뮬레이터에서 안 걸린 이유는
세이브의 `ConfigSetup.ini` 를 손으로 `Language=KO` 로 바꿔서 폴더 이름으로 읽게
했기 때문입니다 — 자동 판별 경로를 한 번도 지나가지 않았습니다.

재발을 막으려고 검증기에 규칙을 넣었습니다. 빌드된 `Data.xml` 의 비번역 필드가 원본
KO 와 다르면 빌드가 실패합니다.

**다만 이 수정만으로 실기 증상이 해결되지는 않았습니다.** 기본 언어를 정하는 건 게임
코드이고 RomFS 에는 그 설정이 없어서, 위에 적은 대로 세이브 수정이 필요합니다.

## v1.1.0에서 바뀐 것 — 주민 말투

게임은 주민 대사를 `성격(5) × 활동(10) × 관계(5)` 로 조합합니다
(`Chat_Greeting_<활동>[<성격>][<관계>]`). 기존 번역은 이 축을 무시하고 있었습니다.

| 결함 | 이전 실측 | v1.1.0 |
|---|---|---|
| 한 주민이 줄마다 말투를 바꿈 | 성격 5종이 **전부** 해요체·반말·합쇼체를 섞어 씀 | 성격 × 관계 칸마다 하나로 통일 |
| 관계가 깊어져도 말투가 안 바뀜 | 존댓 비율 Dislike 53% / Neutral 85% / Friendly 43% / Like 30% / Love 70% — 단계와 무관 | Dislike·Neutral·Friendly=존댓, Like·Love=반말 |
| 인사말이 명사구로 번역됨 | `많은 인사`, `축복받은 인사` 가 262행 앞에 그대로 붙음 | 인사 표현으로 교체 |

| 성격 | 1인칭 | 말버릇 |
|---|---|---|
| 허풍 (Boastful) | 나/내 | 단정·과장 — `~죠`, `~거든요`, `~걸요` |
| 불평 (Complainer) | 나/내 | 투덜 — `~네요`, `~라니까요` |
| 쾌활 (Jovial) | 나/내 | 감탄·권유 — `~요!`, `~할래요?` |
| 독실 (Pious) | **저/제** | 기원문 — `~하기를 바라요` |
| 괴짜 (Quirky) | 나/내 | 엉뚱 — `~거든요`, `~더라고요` |

발화 4,799행을 검사해 1,835행을 고쳤고, 어조 게이트 6종 위반이 **2,132 → 0** 이
됐습니다. 새로 쓴 문장이 쓰는 한글 27자를 폰트 아틀라스에 추가했습니다(83 → 110자).

전체 내역은 [`RELEASE_NOTES.md`](RELEASE_NOTES.md) 에 있습니다.

## 검증 상태

```
PASS (bench)          정적·구조·폰트·이미지·왕복 검증 전부 통과 (errors 0)
PASS (runtime, 부분)   PC/Android Eden 에서 화면 27장 확인 (v1.0.1 빌드 기준)
PENDING (hardware)    실기(Atmosphère) 검증 미수행
```

**v1.1.0 의 어조 교정문과 v1.1.1 의 `Data.xml` 수정은 아직 화면에서 보지
못했습니다.** 특히 v1.1.1 은 `BigGlyphs` 를 원본 KO 값인 `1` 로 되돌립니다. 지금까지
공개한 판은 `0` 으로 나갔고 확인 화면 27장도 그 상태에서 찍은 것이라, 글자 크기·줄
간격이 이전과 달라 보일 수 있습니다. 원본 게임이 KO 슬롯에 쓰던 값이므로 되돌리는
쪽이 맞지만, 확인은 아직 못 했습니다.

아직 못 본 것: 상점·게시판·판매대 이미지 4건, 타이틀 배너, `↩` 기호, 긴 대사 줄바꿈
66행, 실기 동작.

## 제거

넣었던 `romfs` 폴더(또는 모드 폴더)를 지우면 됩니다. 원본 파일을 고치지 않는
overlay 라서 지우면 원래 상태로 완전히 돌아가고, 세이브 데이터에도 영향이 없습니다.
