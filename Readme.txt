====================================================================
 Kynseed 한국어 패치 (Nintendo Switch)
 v1.1.2  /  2026-09-15
 https://github.com/Einbroch/Kynseed-Kor-Patch
====================================================================

Kynseed Switch판의 한국어 슬롯을 고품질 번역으로 교체하는 LayeredFS
패치입니다. 원본 파일을 고치지 않는 overlay 라서, 폴더를 지우면 원래
상태로 완전히 돌아가고 세이브 데이터에도 영향이 없습니다.

Kynseed 는 이미 공식 한국어를 탑재하고 있습니다. 다만 그 번역이 기계번역
품질이라 고유명사가 그대로 남고 주민 말투가 한 줄마다 뒤바뀝니다. 이
패치는 없는 한국어를 새로 만든 게 아니라 기존 한국어 슬롯을 바꿉니다.


--------------------------------------------------------------------
 0. 먼저 확인하세요
--------------------------------------------------------------------

  * 업데이트 1.0.0.54 (v262144) 전용입니다.
    업데이트를 반드시 먼저 설치하세요. 베이스(1.0.0.39)만 있는 상태에
    넣으면 텍스트가 어긋나거나 글자가 빠집니다.

  * Title ID 는 본편 0100783020A1A000 입니다.
    업데이트 쪽(...A800)이 아닙니다. 업데이트를 설치한 상태여도 본편 ID
    폴더에 넣는 것이 맞습니다.

 1. 어느 패키지를 쓸까요
--------------------------------------------------------------------

  0100783020A1A000.zip          기본
                                처음 시작하거나, 이미 한국어로 나오던 경우

  0100783020A1A000-ENslot.zip   EN 슬롯 포함판
                                영어로 플레이하던 세이브가 있는 경우

** 실기(Switch) 에서는 세이브의 ConfigSetup.ini 수정이 필요합니다 **

게임은 선택한 언어를 "세이브 데이터"에 저장하고, 게임 안 설정에는 언어를
바꾸는 항목이 없습니다. 본체 언어를 한국어로 맞추고 세이브 없이 새로
시작해도 게임은 EN 으로 시작합니다 (2026-09-15 실기 확인). 기본 언어를
정하는 건 게임 코드라서 이 패치로는 바꿀 수 없습니다.

  * 기본 패키지를 쓰면 -> 3절의 ConfigSetup.ini 수정이 반드시 필요합니다.

  * EN 슬롯 포함판은 게임이 실제로 읽는 영어 슬롯에도 같은 한국어를 넣어
    두는 판입니다. 세이브를 안 고쳐도 되도록 만들었지만 아직 실기에서
    확인하지 못했습니다. 되는지 알려 주시면 문서를 갱신하겠습니다.
    넣어 둔 동안에는 영어로 되돌릴 수 없습니다(폴더를 지우면 원래대로).

둘 중 하나만 넣으세요. 두 패키지의 한국어 본문은 완전히 같습니다.

 2. 설치
--------------------------------------------------------------------

ZIP 을 풀면 romfs 폴더가 나옵니다. 이 Readme.txt 는 복사할 필요가 없습니다.

[ 실기 (CFW) ]

  Atmosphere 0.10 이상
    /atmosphere/contents/0100783020A1A000/romfs/

  Atmosphere 0.10 미만
    /atmosphere/titles/0100783020A1A000/romfs/

  SX OS
    /sxos/titles/0100783020A1A000/romfs/

  즉 ZIP 안의 romfs/Data/... 가
  /atmosphere/contents/0100783020A1A000/romfs/Data/... 가 되면 됩니다.
  0100783020A1A000 폴더를 한 번 더 만들지 마세요.

[ PC 에뮬레이터 (Eden / Ryujinx 계열) ]

  게임 목록에서 Kynseed 우클릭 -> 모드 폴더 열기

    load/0100783020A1A000/<원하는 이름>/romfs/

  예) load/0100783020A1A000/Korean/romfs/Data/Text/KO/...

[ Android Eden ]

  수동으로 Android/data 아래에 복사하지 마세요. Eden 의 게임별 애드온
  가져오기를 씁니다. RomFS 모드 가져오기 문제가 고쳐진 Eden Stable
  v0.2.1 이상을 권장합니다.

   1) ZIP 을 풀어 Kynseed_KOR 폴더를 만듭니다.
   2) 구조가 Kynseed_KOR/romfs/Data/Text/KO/... 인지 확인합니다.
   3) Eden 에서 Kynseed 를 길게 누릅니다.
   4) 애드온(Add-ons) -> + -> Mods and Cheats 를 고릅니다.
   5) ZIP 이나 romfs 자체가 아니라, 바로 아래에 romfs 가 있는
      Kynseed_KOR 폴더를 고릅니다.
   6) 애드온 목록에서 활성화됐는지 확인하고 Eden 을 완전히 다시 시작합니다.

 3. 한국어가 안 나올 때
--------------------------------------------------------------------

  화면                      의미                  조치
  ----------------------------------------------------------------
  loading (영문)            모드 미적용           설치 경로와 CFW 종류
  + 영어 메뉴                                     를 다시 확인

  로딩 (한글)               모드는 적용됨.        EN 슬롯 포함판으로
  + 영어 메뉴               세이브 언어값이 EN    교체 (또는 아래 방법)

  로딩 + 한국어 메뉴        정상                  -

  한국어가 ㅁ 로 표시       폰트 파일 미적용      font.png / font.json
                                                  경로 확인

로딩이 한글로 나오는데 메뉴만 영어라면 패치는 이미 정상 로드된 상태입니다.
게임이 세이브에 저장해 둔 언어값이 EN 이라 영어 텍스트를 읽고 있을 뿐입니다.
세이브가 없어도, 본체 언어가 한국어여도 이 값은 EN 으로 잡힙니다.

  방법 1 (확인된 방법) - 세이브의 언어값 고치기
    실기  : JKSV / Checkpoint 같은 세이브 관리자로 Kynseed 세이브를
            SD 카드에 백업하고, 백업 폴더의 ConfigSetup.ini 에서
            Language=EN 을 Language=KO 로 바꾼 뒤 복원합니다.
    Android Eden
          : 게임 속성 -> 저장 데이터 -> 내보내기 로 ZIP 을 받고,
            0100783020A1A000/ConfigSetup.ini 를 같은 방법으로 고친 뒤
            ZIP 최상위에 Title ID 폴더가 오도록 다시 압축해 가져오기.

    ** 복원·가져오기는 기존 세이브를 덮어씁니다. 원본 백업을 반드시
       따로 보관하세요. **

  방법 2 (미검증) - EN 슬롯 포함판으로 교체
    0100783020A1A000-ENslot.zip 을 받아 같은 자리에 덮어씁니다.
    세이브를 안 고쳐도 되도록 만든 판이지만 아직 실기 확인 전입니다.
    되는지 알려 주시면 문서를 갱신하겠습니다.

 5. 이 버전에서 바뀐 것
--------------------------------------------------------------------

[ v1.1.2 ] 문서 정정 (패치 파일은 v1.1.1 과 동일)

  실기 확인 결과를 반영했습니다. 세이브 없이 새로 시작해도 게임이 EN 으로
  시작한다는 사실, 그리고 EN 슬롯 포함판이 아직 미검증이라는 점입니다.

[ v1.1.1 ] 언어 슬롯 메타데이터 교정

  게임은 Data/Text/<슬롯>/Data.xml 의 <Code> 로 언어를 고릅니다. 패치의
  빌드 기준이 EN 폴더라서 번역 대상이 아닌 필드까지 EN 값으로 실려
  나갔고, 그 결과 KO 슬롯이 자기를 EN 이라고 말하고 있었습니다.
  한국어로 설정된 본체가 코드 KO 인 언어를 찾으면 없으니 영어로
  떨어졌습니다.

    필드         원본 KO   v1.1.0    v1.1.1
    Code         KO        EN        KO
    Name         Korean    English   Korean
                           Master
    BigGlyphs    1         0         1

  v1.1.0 이하를 쓰고 계시면 갱신하세요.

  다만 이 수정만으로 실기 증상이 해결되지는 않았습니다. 본체 언어를
  한국어로 두고 세이브 없이 새로 시작해도 게임은 여전히 EN 으로
  시작합니다. 3절의 ConfigSetup.ini 수정이 필요합니다.

[ v1.1.0 ] 주민 대사 어조 교정

  게임은 주민 대사를 성격(5) x 활동(10) x 관계(5) 로 조합합니다. 기존
  번역은 이 축을 무시하고 있어서, 한 주민이 한 줄마다 말투를 바꾸고
  관계가 깊어져도 말투가 그대로였습니다.

    성격                1인칭    말버릇
    허풍 Boastful       나/내    단정·과장  ~죠 ~거든요 ~걸요
    불평 Complainer     나/내    투덜       ~네요 ~라니까요
    쾌활 Jovial         나/내    감탄·권유  ~요! ~할래요?
    독실 Pious          저/제    기원문     ~하기를 바라요
    괴짜 Quirky         나/내    엉뚱       ~거든요 ~더라고요

  관계가 Like 단계로 깊어지면 주민이 말을 놓습니다.
  발화 4,799행을 검사해 1,835행을 고쳤습니다.

 6. 알려진 제한
--------------------------------------------------------------------

  1) 업데이트 1.0.0.54 전용입니다. 다른 버전은 동작을 보장하지 않습니다.

  2) 일부 고유명사가 영문으로 남아 있습니다 (97곳). 게임이 원래 배포한
     공식 한국어와 같은 지점이고, 게임이 이름을 영문으로 치환하므로
     화면 표기를 맞추려고 그대로 뒀습니다.

  3) 상점·게시판·판매대 이미지는 아직 화면으로 확인하지 못했습니다.

  5) EN 슬롯 포함판이 세이브 수정 없이 동작하는지 아직 확인하지
     못했습니다.

  4) v1.1.1 은 BigGlyphs 를 원본 KO 값인 1 로 되돌립니다. 이전 판은 0
     으로 나갔기 때문에 글자 크기·줄 간격이 달라 보일 수 있습니다.
     원본 게임이 쓰던 값이라 되돌리는 쪽이 맞지만 확인은 못 했습니다.


--------------------------------------------------------------------
 7. 제거
--------------------------------------------------------------------

넣었던 romfs 폴더(또는 모드 폴더)를 지우면 됩니다. 원본 파일을 고치지
않는 overlay 라서 지우면 원래 상태로 완전히 돌아가고, 세이브 데이터에도
영향이 없습니다.
